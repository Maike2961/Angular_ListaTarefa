# List To Do Application with Angular, Node Typecript, Docker 

## Start the backend and Database with Docker:

```bash
-  docker-compose up -d
-  docker logs <container-name>
```

## Install the dependencies and create a .env file to configure database:

```bash
- npm install
- npm run start:dev
```

## Start the Angular frontend:

```bash
- npm install
- ng server
```
